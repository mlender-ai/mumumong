# 무무몽 디자인 방향 vNext

승인일: 2026-10-14 / 적용일: P2 2026-10-15, P3 2026-10-18, 시각 재대조 2026-10-19, 여백 보정 2026-10-23. 현재 배치는 `MUMUMONG_DESIGN_SYSTEM_v0.9.md`, 빛/재질은 v0.8, 행동 계약은 v0.7, 검증 경계는 `UX_REBUILD_STATUS.md`를 따른다. 아래 P2 절은 당시 기준으로 보존한다.

2026-10-23 여백 지적에 따라 저장/결과의 강제 양끝 정렬을 없애 설명과 행동을32px로 묶고 소개부터 읽기 끝까지 주 행동 폭280px·보조 행동 위계를 공유했다. 큰 진입 화면·표지·색/재질은 유지하며 기능 확장이나 생성 품질 변경은 하지 않는다.

2026-10-19 사용자 요청으로 첨부 7장과 GitHub 커뮤니티 ElevenLabs/Stripe MD를 다시 대조했다. 상부에 모인 블루·라일락, 작은 투명 원고 오브젝트, 중립 유리를 조정하고 온보딩부터 빈 홈까지 검토할 경로와 명시적 9상태 Orb 리뷰를 추가했다. 실제 대기 밖 Orb는 이 로컬 컴포넌트 리뷰에서만 허용한다. P4 잔여 기능·Q 기준선·실제 생성/동의 계약을 바꾸거나 운영 배포하지 않았다.

사용자가 전달 패키지를 검토한 뒤 “진행해 하나씩”으로 착수를 승인했다. 이 문서는 패키지의 시각 요구를 정본으로 기록한다. 제품의 일곱 단계 루프, D/C/U 출처, U 잠금, 동의/RLS, 무본문 로그, 영속 저장과 Q-series frozen baseline은 유지한다.

## 방향

### 첫 꿈 경험 우선 — 2026-10-22 요청, 10-23 실행

새 MVP 지시서와 사용자 강조에 따라 ‘첫 꿈 기록 → 내 작품으로 읽기 → 다시 기록하고 싶은 경험’을 연속 창작 확장보다 우선한다. 기존 Flutter/Supabase 구현을 재사용한다. 저장 직후는 해석·감정 추정 없는 짧은 수용 문구, 첫 결과는 진척 숫자보다 장면 자체, 첫 장면 읽기 끝은 원문 재확인/읽기 마치기로 연결한다. 디자인과 실제 동작을 함께 검증한다.

이번 비LLM 첫 단위는 AI 감정 응답·짧은 독립 작품 생성·작품 완결 구현이 아니다. 새 문서의 장면 단위 출처 제안 때문에 기존 D/C/U·U 잠금 정보를 지우지 않는다. 전면 하프톤이나 타이핑/STT 반복 효과도 복원하지 않는다. 감정 응답 추가·분량 정책 변경은 Q 측정/동결 계약과 함께 검토하고, 독립 작품/이어가기 선택은 실제 저장·생성 대상 계약을 만든 뒤 노출한다. 작동하지 않는 선택 버튼으로 먼저 꾸미지 않는다.

명확한 사용성과 하나의 핵심 행동 위에 꿈의 분위기를 얹는다. 토스는 행동 위계의 참고다. 화면마다 무엇을 해야 하는지 한눈에 보여야 하며, 뒤로가기·닫기·선택적 상세 설정은 접근 가능하게 유지한다.

빛은 한 곳에 모이고 나머지 공간은 깨끗하게 정돈된다. 흰색 바탕에 블루·라일락 빛이 사라지는 경계를 만든다. 전체 화면을 같은 강도의 블러로 채우지 않는다. 밤 테마는 같은 구조를 유지하며 짙은 바탕에 제한된 블루 발광을 사용한다. P3에서 앱 표시 설정으로 연결했으며 실제 브라우저/PWA 시스템 크롬 일치는 별도 검수 대상이다.

## 공통 시스템의 출발점

기존 `lib/core/design/design_system.dart`를 통합 지점으로 유지한다. 별도 화면별 디자인 시스템을 만들지 않는다. P2에서 실제 실행 화면을 비교한 뒤 P3에서 전체 적용한다.

- 바탕: `paper #FFFFFF`, 보조 면 `paperShade #F3F4F4`.
- 글자: `ink #1E1D1B`, 보조 `ink2 #55524D`, 메타 `ink3 #74716B`. 밝은 바탕의 제목·설명은 잉크색을 우선한다.
- 빛: 기존 스카이블루/라일락 계열을 유지하되 색의 중심, 범위, 페이드 경계를 별도 구성한다. 선택 표시와 새 생성 표시의 의미를 분리한다.
- UI: Pretendard. Reader: MaruBuri를 시작점으로 가독성을 비교한다. 숫자 규격은 v0.6의 타입 스케일을 출발점으로 한다.
- 간격: 4px 리듬, 화면 여백 24px. 주 행동 높이 52px, 터치 영역 최소 44×44px. 입력면 20px, 시트/패널 28px, 버튼은 pill.
- 유리: 행동면·입력면·작은 오버레이에 한정한다. 밝은 바탕에서도 라벨·테두리·눌림이 보여야 한다. 긴 본문에는 사용하지 않는다. Apple 전용 버튼은 출시 전 공식 브랜딩 검토가 필요하다.
- 모달: 최대 폭 480px, 24px 내용 여백, SafeArea와 키보드에 맞춘 스크롤. 시트와 입력 필드를 고정 높이로 압축하지 않는다.

## 모션·성능·접근성

선택 반응 120–240ms, 화면 전환 300–420ms를 출발점으로 사용한다. 실제 기기 측정 전에는 성능 수치를 보장하지 않는다. 저장 성공 후 저장 연출, 실제 작업 단계에 따른 생성 연출, 로컬 결과 동기화 후 리빌, 실제 증가 이벤트 후 성장 연출만 허용한다.

픽셀/ASCII는 소량의 상태 오브젝트에만 사용한다. 필수 문구·버튼을 대체하거나 읽기 본문과 겹치지 않는다. P2의 첫 비교는 저장/성장 전환 한 곳에서 시작한다. 입력과 음성 전사 중 전체 화면 repaint·blur 재계산·beam·문자마다 부모 rebuild는 추가하지 않는다.

동작 줄이기에서는 같은 정보를 정적인 오브젝트와 짧은 페이드로 전달한다. 긴 전환은 건너뛸 수 있어야 하며 가짜 퍼센트나 고정 타이머로 생성 완료를 만들지 않는다.

검증 크기: 375×667, 390×844, 430×932와 넓은 웹. 키보드, 큰 글자, 밝은/밤 테마, 동작 줄이기, 오류/긴 대기를 검증한다. P0 캡처는 390×844의 현재 화면 기준선이고 새 시안이 아니다.

## P2 실행 규격 — 2026-10-15

이 절은 위 방향을 실제 네 화면에 적용한 규격이다. v0.6의 이전 홈 메쉬·168px 덮개·버튼 푸른 광채와 다르면 이 절과 실행 코드가 우선한다. 전체 설정·보관함·첫 원고·Reader UI 이행은 P3에서 진행한다.

| 요소 | 실행 규격 |
|---|---|
| 빛 | 공유 `DreamAtmosphere`. 블루 `#8BCBEF`, 라일락 `#717FC9`, 블루 초점 `#248CCD`, 흰빛 `#D8F3FC`. 중심을 화면 상부 22–43%에 모으고 field 높이의 43–88%에서 바탕으로 페이드. 상단 18%는 시스템 바탕에서 연속적으로 나타남 |
| 소개 | 빛 높이 화면의 58%(280–520px), 최대 폭 720px. 내용 최대 폭 620px/여백 24px. 하단 제목은 잉크색 산세리프, 하나의 중립 유리 주 행동. 동의는 같은 흐름의 별도 화면 |
| 입력 | 정적인 약한 빛(.12), 키보드가 열리면 제거. UI 산세리프 입력면·저장 행동. 타이핑/STT 중 Orb·beam·픽셀·오디오 레벨 repaint 없음 |
| 저장 확인 | Repository 저장 완료 뒤에만 32px/7개 셀의 MemoryStamp를 650ms에 한 번 모음. 보강 질문의 선택적 분리는 P3에서 작업 |
| 처리 | published `thinking_orbs` 0.2.0의 native 64px Orb와 짧은 상태 문구. 실제 job 단계가 working/connecting/composing/solving을 선택. 정적 120px 빛만 사용, 큰 카드·카운터·가짜 퍼센트 없음 |
| 결과 | 로컬 결과 수신 뒤 실제 제목·첫 문단(최대 5줄)·실제 증가량, 주 행동 ‘새 장면 읽기’. 전체 본문은 정확한 sceneId Reader에서 읽음. 연결·배치는 보조 ‘장면 조정하기’ 시트 |
| 주 행동 | 높이 최소 52px, pill, 중립 반투명 면·얇은 경계·한 겹 그림자. 라벨은 길어지거나 큰 글자일 때 높이가 성장. 블루 채움·푸른 그림자 제거. 눌림 scale .975/120ms, 튐 없음 |
| 화면 전환 | capture phase 360ms, 소개/페이지 420ms. 실제 저장/job/result 상태에서만 전환. 전환 장식이 완료 상태를 만들지 않음 |
| 반복 모션 | 14초 주기 중심 이동. CustomPainter repaint와 RepaintBoundary만 갱신, 부모 widget frame rebuild/전면 BackdropFilter 없음 |
| 동작 줄이기 | 빛은 고정 phase .24, 저장 스탬프는 완성형, 긴 phase/page 전환 생략. 버튼 눌림도 duration 0 |
| 야간 후보 | 동일 구조, field 바탕 `#050C18`, 기존 nightInk/nightMeta와 제한된 블루 빛. 네 화면 ThemeData 비교용이며 전역 토글·영속 theme/system-bar 색 변경은 아직 없음 |

밝은/야간 후보의 375×667·390×844·430×932·1200×800와 작은 화면 1.6배 글자를 40개 widget 이미지로 확인했다. 375×667/290px keyboard inset/1.5배 글자도 통과했다. 시각·동작 증거와 실제 서비스/실기기 미검증 경계는 [P2 리뷰](ux-review/2026-10-15-p2/README.md)를 따른다. Apple 전용 버튼 브랜딩은 출시 전 별도 검수 대상이다.
