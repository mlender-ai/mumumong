# MUMUMONG Design System v0.7

2026-10-18 · P3 실행 규격. 승인된 `DESIGN_DIRECTION_vNext.md`를 구현했으며 v0.6의 오래된 화면·재질·야간 범위를 대체한다. 제품 루프, D/C/U, U 잠금, 동의/RLS와 Q 동결 기준은 유지한다. 정본 코드: `lib/core/design/design_system.dart`, `dream_atmosphere.dart`, `ui_preferences.dart`.

## 1. 화면과 행동

한 화면에 한 가지 **시각적 주 행동**. 주 행동은 글래스, 보조 경로는 TextButton·아이콘·내비게이션 행이다. 카드 대시보드나 긴 본문 위 장식은 만들지 않는다.

| 화면 | 주 행동 | 보조 경로 |
|---|---|---|
| 소개 | 계정 시작 → 고지 확인 | 가상 꿈 미리 보기(실제 AI 결과가 아님을 명시) |
| 고지 | 연령/AI 개별 동의 후 계속 | 실제 제공사 링크 열기·주소 복사 |
| 첫 원고 | 기본 설정으로 시작 | 상세 각색·문체·시점, 실제 선택값 요약 |
| 기록 | 꿈 저장하기 | 지원 기기 음성·닫기 |
| 저장 성공 | 장면 만들기 | 기억 보강·나중에 만들기 |
| 선택적 보강 | 보강 마치기 | 전체 건너뛰기; 두 행동 모두 생성 없이 저장 단계로 복귀 |
| 처리 | Orb와 짧고 안정적인 상태 | 닫기·나중에 확인하기. 연결 오류는 상태 재확인, 실제 실패에서만 재시도(P4 첫 단위) |
| 새 장면 | 새 장면 읽기 | 연결·배치 조정 시트 |
| 홈 | 미열람 장면이 있으면 새 장면 읽기, 없으면 꿈 기록하기 | 기록·이어 읽기·보관함 상태 확인 |
| 보관함 | 선택한 꿈/결과 열기 | 필터·원문 수정·삭제·저장한 꿈 생성 시작 |
| 설정 | 항목별 상세 화면으로 이동 | 화면과 읽기·JSON 데이터 관리·앱 잠금·AI/음성 안내 |

새 장면 판단은 로컬 본문과 첫 문단의 열람 마커를 사용한다. Reader가 장면을 열면 기존 `markPassageRead`로 첫 문단의 마커를 기록한다. 완독/시선 추적이 아니며, 세밀한 결과 소비·알림 중복 처리는 P4 범위다.

## 2. 의미 색 역할

화면은 BuildContext의 `canvas/raised/subtle/primaryInk/secondaryInk/metaInk/hairline`을 사용한다. 원시 색을 화면마다 새로 고르지 않는다.

| 역할 | 밝게 | 어둡게 |
|---|---|---|
| 바탕 | #FFFFFF | #050C18 |
| 시트/모달 | #FFFFFF | #111C2B |
| 보조 면 | #F3F4F4 | #152131 |
| 본문 | #1E1D1B | #E8E5DF |
| 설명 | #55524D | #BEC7D1 |
| 메타 | #74716B | #A5B2C1 |
| 경계 | #E8E5DF | #314055 |

Reader 밤 종이는 기존 #161513로 유지한다. 스카이는 선택 경계·처리·빛에 사용하며 주 버튼을 파란색으로 채우지 않는다. GNB 바탕도 현재 앱 canvas와 맞춘다.

## 3. 서체와 규격

UI는 Pretendard, 원고는 MaruBuri. 크기/행간: 소개 36/1.20, 화면 제목 28/1.30, 시트 제목 22/1.35, 상태 제목 18/1.40, UI 본문 16/1.55, 설명 14/1.50, 행동 15/1.25, 칩/탭 13/1.40, 메타 12/1.40, 원고 18/1.75. 제목·행동 600, 본문 400.

- 4px 리듬 `4/8/12/16/24/32/48`, 화면·시트 여백 24px.
- 터치 최소 44×44px. 주 행동은 **최소** 높이 52px이며 큰 글자/긴 라벨에 따라 성장한다. pill, 입력 radius 20px, 시트/패널 28px.
- 입력/동의/설정 폭 최대 620px, 홈/보관함/Reader 720px. 읽기 본문은 그 안쪽 여백에 배치한다.
- 시트·모달 최대 폭 480px. 키보드에서는 스크롤로 필드/행동에 접근한다. handle 36×4px.
- 시스템 글자 확대를 유지한다. 앱 읽기 크기 `.9/1/1.2/1.4`는 원고 본문에만 적용하며 시스템 TextScaler와 함께 작동한다. 크기가 달라지면 문단 앵커로 읽기 위치를 보정한다.

## 4. 컴포넌트 상태

`GlassActionButton`과 호환 `EditorialButton`은 같은 renderer다. 중립 반투명 흰색 그라데이션·22px blur·1px 경계·한 겹 그림자. 밝은 바탕은 잉크 라벨, 야간은 밝은 라벨. 눌림 .975/120ms, 튀는 복원 없음. 저장 중에는 중복 실행을 막는다. 칩은 44px 최소 높이와 선택 경계, 보조 행동은 TextButton이다.

Reader의 문단 메뉴에서 출처/수정/원래 문장으로를 찾을 수 있다. 원래 문장 복원은 명시적으로 확인한다. Reader·꿈 원문 편집은 저장 실패 시 창과 입력을 보존하고, 성공한 뒤에만 닫는다. U 잠금/출처 복원은 기존 Repository 계약을 따른다.

JSON은 꿈 원문·초안까지 포함하는 데이터 사본이다. 책 PDF는 P5 완성본 기능이며 지금 저장 가능한 것처럼 표시하지 않는다. Apple 전용 브랜드 버튼 승인은 출시 전 별도 검수다.

## 5. 모션

P2 `DreamAtmosphere` 유지: #8BCBEF/#717FC9/#248CCD/#D8F3FC의 상부 22–43% 초점, field 43–88%에서 바탕으로 소멸, 14초 반복 painter/RepaintBoundary. 입력은 정적이고 키보드에서 약한 배경 빛도 숨긴다. 저장 성공 한 곳의 32px MemoryStamp만 650ms 한 번 모인다.

실제 처리에는 published `thinking_orbs` 0.2.0 native 64px. 화면 전환 360–420ms, 클릭 120–240ms. 동작 줄이기는 반복을 정지하고 스탬프를 완성형으로 두며 긴 전환을 생략한다. 가짜 완료 타이머/퍼센트는 없다.

## 6. 표시 설정과 시스템 영역

밝게/어둡게/기기 설정, 원고 글자 크기, 출처 표시를 기기 `shared_preferences`에 저장한다. 기본은 밝게/1.0/출처 표시 끄기. 저장 실패에서는 이전 값을 유지하고 오류를 알린다. 원문·원고·인증 정보는 이 저장소에 넣지 않는다. 각색/문체/시점의 이후 생성분 변경은 P4다.

네이티브 상태 영역은 앱 테마/Reader 종이색으로 맞추고 복귀한다. 웹 시작 HTML·브라우저/PWA 크롬은 Flutter 영역과 다르다. 초기 white flash, 실제 Safari/PWA 상태바 일치는 실기기 검수 대상이며 페이지가 주소/도구 막대를 제거한다고 약속하지 않는다.

## 7. 검증 경계

[P3 화면·검증 기록](ux-review/2026-10-18-p3/README.md)을 따른다. Memory/mock은 실제 AI 품질의 증거가 아니다. 물리 iPhone/PWA·STT·터치 지연/프레임·사용자 5명 실험은 미검증이다. P3는 운영 재배포를 포함하지 않는다.

### P4 첫 단위의 상태 계약

정상 처리 화면은 같은 64px Orb·안정적인 한 줄·낮은 위계의 ‘나중에 확인하기’만 보인다. 네트워크/다운로드 오류에서 ‘장면을 만들지 못했어요’라고 단정하지 않는다. ‘상태 다시 확인’은 관찰만 재시작하며 새 원고를 만들지 않는다. 접수 응답이 불명확한 경우에만 같은 idempotency 키의 ‘접수 다시 확인’을 보조 경로로 제공한다. 실제 job failed일 때만 ‘다시 시도’가 주 행동이다. 결과 본문을 받기 전에는 리빌하지 않는다.
