# 첫 꿈 경험 · 비LLM 첫 단위

2026-10-22 착수 / **2026-10-23 KST 검증**. 새 MVP 지시서의 ‘첫 작품을 읽고 두 번째 꿈을 남기고 싶은 경험’을 연속 창작 확장보다 우선했다. 이 작업은 UI 첫 단위이며 **AI 감정 피드백·생성 품질·첫 작품 완결을 완성한 것이 아니다**. 공개 사이트는10/22 배포 상태 그대로다.

## 구현 범위

- 저장 성공 후 ‘떠오른 만큼 남겼다면 충분해요. 지금 이야기로 만들지 않아도 괜찮아요.’를 표시한다. 정적인 제품 안내이지 AI가 감정을 분석한 문장이 아니다. 저장만 하기와 선택적 보강 경로를 유지한다.
- 리빌은 해당 권에 실제 로컬 반영된 장면이 하나일 때만 첫 장면 안내를 사용하고 +%를 숨긴다. 라우트의 꿈/장면 번호를 첫 결과 여부의 근거로 쓰지 않는다. 생성 본문/제목/길이/진척 이벤트는 그대로다. 먼저 읽기와 원문 보관 안내를 제공한다.
- 장면이 하나이고 본문이 있는 Reader 끝에 ‘첫 장면은 여기에 남아 있어요’, ‘읽기 마치기’, ‘꿈 원문 다시 보기’를 제공한다. 원문은 기존 출처 시트로 실제 저장된 꿈을 조회한다. D 출처를 찾을 수 없으면 원문 버튼을 표시하지 않는다. 닫기는 원래 화면으로 돌아가며 생성/작품 완결/PDF 저장은 실행하지 않는다. 읽기 마침을 완독률 이벤트로 기록하지도 않는다.
- 홈 SafeArea가 Scaffold.extendBody의 실제 하단 GNB inset을 반영하도록 수정했다. 큰 글자에서 주 행동이 내비게이션 아래의 스크롤 영역에 남는 문제를 막는다. 표지 높이 산식은 inset을 보정해 기존 큰 표지를 유지한다.
- 입력/STT는 정적, 처리만 기존 Orb. 새 제공사/모델/LLM 단계/엔진/Q/SQL/스키마 변경 없음. 실제 생성 원고를 DB로 직접 교정하지 않았다. 기존 읽음 마커·읽기 위치 저장은 그대로 사용한다.

### 발견해서 수정한 것

- 최초 widget 테스트는 Stream.first를 fake-async 바깥에서 기다려 정지했다. 해당 실행을 중단하고 저장소 snapshot 관찰을 tester.runAsync로 옮겼다. 최종234개 재실행은 통과했다.
- 첫 크기 매트릭스에서375×667/글자1.6배의 홈 버튼이 GNB와 겹쳤다. SafeArea/inset을 수정하고 실제 클릭 성공을 재검증했다. 경고를 숨기거나 좌표로 우회하지 않았다.
- 읽기 끝 golden은 scroll 후 paint를 기다리지 않아 이전 화면을 캡처했다. 명시적 pump 및 버튼 bounds 검사를 추가해 새 기준을 만들고 다시 비교했다.
- `flutter analyze --no-pub`는 기존 한국어 경로의 LSP JSON 오류(exit255)로 실패했다. 직접 분석 통과와 구분한다. ASCII 사본으로 원본 검증을 대체하지 않았다.

## 미검증·다음 작업

실제 hosted 계정/AI/RLS·소설 충실도와 재미·실제 재방문/두 번째 꿈 기록률, 물리 iPhone/PWA·키보드/STT/프레임·터치 성능은 이번에 검증하지 않았다. 글과 버튼만 개선해 위 지표가 올랐다고 주장하지 않는다. 공개 재배포/commit/push 없음.

다음은 첫 결과의 실제 품질 검토와 감정 응답의 안전한 별도 계약이다. 감정을 원문 근거 없이 추정하거나 위로/진단을 만들어내지 않는다. Q 측정·동결을 유지하며 정보량에 맞는 짧은 생성/분량 정책은 품질 절차 안에서 검토한다. 독립 작품과 이어가기·완결 선택은 실제 데이터/생성 대상 계약이 필요하며 이 UI 단위의 완료 범위가 아니다. 기존 P4 잔여도 완료 처리하지 않는다.
