## 9. GO / RETURN

- **GO**: 브랜치에 커밋 → `AuthGate`·동의 게이트·클라우드 부트스트랩을 V2 화면에 연결(생성자 계약이 같다) → 설정·완성 화면 V2 이전 → V1 UI 테스트를 V2 기준으로 이관 → 실기기·호스팅 검증 → 보호된 미리보기 배포 → 단계 배포. `main` 병합과 프로덕션 배포는 각 단계에서 다시 확인받는다.
- **RETURN**: 아무것도 되돌릴 필요가 없다. V1은 그대로다. 브랜치·워크트리·태그는 보관하거나 지운다.

## 10. GO 1단계: 실제 앱 연결 (2026-10-27)

브랜치 커밋 `f49be43`(미리보기) 위에 이어서 작업했고, 이 단계는 같은 브랜치에 별도 커밋으로 남겼다. push·병합·배포는 하지 않았다.

**무엇이 바뀌었나**

- `lib/main.dart`가 `--dart-define=UI=v2`이면 V2를 띄운다. 기본값은 `UI=v1`이라 플래그 없이 빌드하면 지금 배포본과 같다.
- 인증·동의·클라우드 부트스트랩 관문은 V1 코드 한 벌을 그대로 쓴다. 관문은 규칙만 정하고, 화면은 `AuthPresentation`이 그린다. V1 그리기는 기존 화면 그대로이고 V2 그리기는 `lib/v2/screens/gates.dart`다.
- 앱 잠금은 같은 `AppLockGate`에 V2 잠금 화면을 넘긴다.
- 설정 전체를 V2 페이지로 옮겼다: 읽기와 종이, 이후 장면 설정, 기록 관리, 앱 잠금, AI 처리 고지, 음성 기록.
- 기록 내보내기와 전체 삭제는 V1·V2 공용 `RecordActions` 한 곳에서만 실행한다. 미리보기에서는 실행하지 않는다.
- 완성한 책과 완성 요청은 아직 V1 화면이다. V1 브리지로 열어 하위 화면까지 V1 테마를 유지한다.

**실행**

```bash
cd ../무무몽-v2 && flutter run -t lib/main.dart --dart-define=UI=v2 --dart-define=ENV=dev --dart-define=ENGINE=mock
```

로그인 관문까지 보려면 `--dart-define=AUTH=apple --dart-define=ENGINE=remote`를 더한다. ENV=dev는 로컬 Supabase(127.0.0.1:54321)를 쓴다.

### 찾아서 고친 결함 4가지

위젯 테스트로는 보이지 않던 것들이다. 각각 회귀 테스트를 더했다. 기록 화면과 버튼 테스트는 고치기 전 코드에서 실패하는 것도 확인했다.

1. **리더 상태 막대 비침** (`dev-06`, `dev-10`): 스크롤한 원고가 떠 있는 헤더 위, 시계 밑으로 비쳐 보였다. `V2EdgeFade`에 `inset`을 더해 리더가 상태 막대 높이까지는 아무것도 그리지 않고, 그 아래에서 흐리게 나타나게 했다. 설정·홈·보관함은 이미 SafeArea 안이라 문제가 없었다.
2. **대화상자 단어 중간 줄바꿈** (`dev-11` → `dev-13`): 내보내기 확인 문구가 “화면에 / 서”로 끊겼다. 대화상자 본문, `V2Notice`, 토스트, 기록 입력란 안내 문구에 keep-all을 컴포넌트에서 적용했다.
3. **가장 큰 글자에서 기록 불가** (`dev-15` → `dev-17`): 질문 제목이 화면을 다 차지해 입력란 높이가 0이 되고, 21px이 넘치고, 저장 버튼이 잘렸다. 이미 큰 디스플레이 제목은 iOS 큰 제목처럼 1.5배에서 멈추게 했다. 보관함 제목도 같다.
4. **가장 큰 글자에서 컨트롤 잘림** (`dev-16`·`dev-19`·`dev-20` → `dev-18`·`dev-21`): 버튼 글자 아래가 잘리고, 보관함 필터가 “원고…”, 리더 헤더가 “VOL.01 · 이…”로 잘렸다. 높이가 정해진 `V2Button`·`V2Segmented`·`V2ContextHeader` 제목은 1.6배에서 멈춘다(플로팅 내비는 원래 1.25배). 본문·원고·입력은 끝까지 커진다.

## 17. 호스팅 검증: 일회용 합성 계정, mock 엔진 (2026-10-28)

허락받은 범위: 일회용 합성 계정 사용, 실제 AI 호출 없음(mock), 배포 없음. 호스팅 백엔드에는 서버 쪽 mock 생성이 없어 생성은 서버에 보내지 않았다. 앱은 `UI=v2 ENV=staging ENGINE=mock AUTH=apple`로 빌드해 **인증·AI 처리 고지·동의 기록·계정 삭제만 호스팅 Supabase(staging 프로젝트)**를 쓰고, 장면 생성은 앱 안의 고정 mock으로 했다. 공개 키는 Supabase CLI에서 빌드 명령으로 바로 넘기고 출력·저장하지 않았다.

### 수동 검수 (QA 시뮬레이터, 캡처 `device/host-01`~`host-12`)

| 단계 | 결과 |
|---|---|
| 로그아웃 상태 시작 | V2 온보딩 |
| 시작 → 동의 화면 | 서버의 AI 처리 고지(Groq, 고지 버전 1)를 불러와 V2로 표시 |
| 두 항목 체크 → 체험 계정으로 시작 | 서버에 익명 계정 생성, 동의 기록, 새 계정이라 V2 권 설정 화면 |
| 시작하기 → 첫 꿈 → 장면 만들기 | 빈 원고(0%)에서 시작, mock 엔진으로 “내 꿈에서 시작한 첫 장면이에요” |
| 설정 → AI 처리 고지 | 서버 고지를 단어 단위 줄바꿈으로 표시 |
| 기록 관리 → 모든 기록 삭제(“삭제” 입력) | 서버 `delete-account` 성공 → 로컬 DB 비움(volumes·scenes·dreams·passages 0행 확인) → 로그아웃 |
| 앱 다시 열기 | 로그아웃 상태 온보딩 |

### 자동 검증 (`integration_test/v2/hosted_account_test.dart`)

같은 흐름을 통합 테스트로 만들었다. `--dart-define=HOSTED_QA=true`와 staging 설정이 있을 때만 돌고, 평소 `flutter test integration_test/v2`에서는 건너뛴다. 삭제 전 받은 접근 토큰으로 삭제 뒤 서버에 사용자를 물으면 **서버가 그 사용자를 모른다**는 것까지 확인한다. 테스트가 중간에 실패해도 `finally`에서 같은 토큰으로 계정을 지운다. QA 시뮬레이터에서 1회 통과(29초). 로그에 키·토큰이 없음을 확인했다.

만든 일회용 계정은 2개(수동 1, 자동 1)이며 둘 다 앱의 삭제 경로로 지웠다. 자동 쪽은 서버에서 사라진 것을 확인했고, 수동 쪽은 서버 함수가 성공을 돌려준 뒤에만 로컬 삭제가 진행되는 코드 경로와 DB가 비워진 것으로 확인했다.

### 찾아서 고친 것 (V2 표시 계층)

1. **동의 화면의 서버 고지 줄바꿈** (`host-03`): 서버에서 온 고지 본문이 “전송 / 됩니다”, “모 / 델”처럼 끊겼다. 설정의 고지 화면은 이미 keep-all이었고 동의 화면만 빠져 있었다. 고쳤고 `gates_test`에 확인을 더했다.
2. **홈 설정 버튼의 의미 라벨**: 전체 설정을 여는 버튼을 VoiceOver가 “읽기 설정”이라고 읽었다(리더의 글자 버튼과 같은 이름). “설정”으로 바꾸고 `flow_test`에 테스트를 더했다.

### 찾았지만 고치지 않은 것 (공유 계층, 결정 필요)

**모든 기록 삭제 직후 화면이 지워진 원고를 계속 보여 준다** (`host-10`, `host-11`). 서버 계정과 로컬 DB는 실제로 지워졌고 로그아웃도 됐지만, 앱을 다시 열기 전까지 홈이 삭제된 원고(장면 1 · 꿈 1)를 보이고 관문도 로그인 상태로 남는다. 원인 두 가지는 모두 V1과 같이 쓰는 코드다.

- `lib/data/local/local_data_control.dart`의 `clearLocalData`가 `customStatement`로 지워 Drift 감시 스트림에 변경을 알리지 않는다.
- `DeviceRecordActions.deleteEverything`이 Supabase `signOut`을 직접 부르고, `AuthenticationController`에는 로그아웃 전환이 없어 관문이 모른다.

코드 경로가 같아 V1도 같을 것으로 보지만 V1으로 실행해 확인하지는 않았다. 고치려면 `lib/data`·`lib/ui/settings`(공유 계층)를 바꿔야 해서 “디자인 때문에 데이터·백엔드를 임의로 바꾸지 않는다”는 지시에 따라 멈췄다. 이 상태에서 사용자가 계속 쓰면 계정 없는 로컬 기록이 새로 생길 수 있다.

### 아직 확인하지 않은 호스팅 경로

- `ENGINE=remote`의 클라우드 부트스트랩·꿈 동기화·이후 장면 설정 서버 저장·서버 완성본: 원격 엔진 모드는 생성 시 실제 AI를 부르는 경로라 이번 범위(mock)에서 뺐다. “장면 만들기”를 누르지 않으면 AI 호출 없이 동기화만 확인할 수 있지만, 허락 범위를 넘으므로 묻는다.
- Apple 로그인: 시뮬레이터에 Apple ID가 없고 암호는 입력하지 않는다.
- 호스팅 웹 미리보기: 배포라 승인 필요.
