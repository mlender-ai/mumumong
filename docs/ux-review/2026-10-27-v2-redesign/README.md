## 2. 실행 방법

시뮬레이터(17 Pro에는 지금 V2 미리보기가 설치돼 있다. 홈 화면의 무무몽 아이콘으로 바로 열 수 있다):

```bash
cd ../무무몽-v2 && flutter run -t lib/main_v2.dart --dart-define=ENV=dev --dart-define=ENGINE=mock
```

웹 미리보기(로컬 전용):

```bash
cd ../무무몽-v2 && flutter build web --release -t lib/main_v2.dart --dart-define=ENV=dev --dart-define=ENGINE=mock -o build/web_v2 && python3 -m http.server 8792 --bind 127.0.0.1 --directory build/web_v2
```

V1을 같은 시뮬레이터에서 다시 보려면 원래 체크아웃에서 `flutter run --dart-define=ENV=dev --dart-define=ENGINE=mock --dart-define=AUTH=local`.

런처 세 가지: **처음 시작하기**(온보딩→동의→첫 원고→빈 원고), **이어 쓰기**(가상 원고 42%), **디자인 랩**(컴포넌트·도트 단독 시연). 가짜 엔진 결과(성공·재시도·대체·실패)와 음성(미리보기 음성·기기 음성 인식)을 고를 수 있다. 홈 오른쪽 위 설정 시트에 “미리보기 처음으로”가 있다.

## 8. 미검증 (로컬 실기기 필요)

- 실기기 렌더링(블러·그림자·120Hz 모션·햅틱 체감). 테스트 렌더러는 블러와 그림자를 그리지 않아 이 품질은 시뮬레이터 화면으로만 봤다.
- OS 동작 줄이기 토글: simctl로 켤 수 없어 테스트의 접근성 값으로만 검증했다.
- 실제 음성 인식과 진폭 반응: 네이티브 채널이 rms를 보내지 않는다.
- 소프트웨어 키보드가 실제로 올라온 상태: 시뮬레이터는 하드웨어 키보드였고 테스트 인셋으로만 검증했다.
- 원격 엔진·인증·동의 제출이 있는 실제 흐름: V2는 아직 `AuthGate`에 연결하지 않았다(GO 이후).
- `supabase test db`: SQL 변경이 없어 실행하지 않았다.

## 9. GO / RETURN

- **GO**: 브랜치에 커밋 → `AuthGate`·동의 게이트·클라우드 부트스트랩을 V2 화면에 연결(생성자 계약이 같다) → 설정·완성 화면 V2 이전 → V1 UI 테스트를 V2 기준으로 이관 → 실기기·호스팅 검증 → 보호된 미리보기 배포 → 단계 배포. `main` 병합과 프로덕션 배포는 각 단계에서 다시 확인받는다.
- **RETURN**: 아무것도 되돌릴 필요가 없다. V1은 그대로다. 브랜치·워크트리·태그는 보관하거나 지운다.
