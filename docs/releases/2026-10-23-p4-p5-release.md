## 실패 / 남은 위험

1. 실제 AI 두 건은 **V2 길이**, 한 건은 **V5 충실도**도 실패해 commit까지 못 갔다. Q 실측/사람 판정 없이 프롬프트를 풀거나 DB 원고를 직접 교정하지 않았다. 현재 trial은 생성이 실패할 수 있으며 완성본/PDF 추가가 이 문제를 해결한 것은 아니다.
2. hosted 충돌 첫 검증은 SQLSTATE40001 자동 반복으로 timeout됐다. forward migration0020의PT409로 수정 후 재검증했다. [Supabase 공식 알려진 원인](https://supabase.com/docs/guides/troubleshooting/high-cpu-and-infinite-transaction-retries-when-using-custom-error-codes-in-rpc-functions-77326b).
3. 물리 iPhone/PWA 키보드·STT10회·터치/프레임·PDF OS 공유/파일 저장·cold-start offline 인증/동의·실제 다기기 동시 편집은 미검증이다. Native 시뮬레이터 검증은 App Store 배포나 실제 기기 검수가 아니다.
4. OS push·완전한 retry-intent 복원·독립 첫 작품/연속 창작 선택 경험·사용자5명/재방문 행동 검수는 남는다. LLM 완결 편집은 Q32 이후. Q 비공개 자료와 로컬 키는 사용자 미준비 상태다.
5. 비용/지연 운영 집계는 기존 generation_runs와 queue metadata에 한정한다. client funnel을 중앙 수집하거나 성능을 측정했다고 주장하지 않는다. 검증 계정 삭제 후 운영 집계는 queue0/stalled0/cron실패0이었으며 이를 AI 성공률로 쓰지 않는다.
