# MUMUMONG Design System v0.9

2026-10-23 · 여백과 행동 위계 정렬. v0.8의 팔레트·글래스 재질·큰 진입 화면·모션은 유지하고 아래 배치 규격만 대체한다. 공개 배포 완료 문서가 아니다.

## 문제와 적용 원칙

저장/결과 화면의 `spaceBetween`이 설명과 행동을 화면 양 끝으로 분리했다. 소개의 280px 버튼과 이후 화면의 넓은 버튼, 같은 무게의 보조 행동, 옅은 읽기 끝 설명도 서로 다른 인상을 만들었다. 여백을 일괄 축소하지 않고 관련 설명과 행동을 하나의 묶음으로 만든다.

## 공유 규격

| 항목 | 규격 |
|---|---|
| 단계 화면 | `MongFlowPage`: 좌우/상하 24px, 설명→행동 32px, 묶음 전체 수직 중앙 |
| 작은 화면·큰 글자 | 최소 콘텐츠 높이만 확보하고 넘치면 스크롤. 고정 높이·강제 줄임 없음 |
| 주 행동 | `MongActionGroup`: 최대 280px, 좁은 화면에서는 가용 폭, 최소 높이 52px |
| 보조 행동 | 주 행동 아래 8px, Wrap 중앙 배치, 항목 사이 8px, 최소 터치 44px, labelLarge 15px/400 |
| 내용 리듬 | 상태→메타 8px, 메타→장면 제목 24px, 제목→본문 16px, 본문→출처 8px |
| 읽기 끝 | 원고→구분선 32px, 구분선→설명 24px, 설명→행동 32px |
| 텍스트 위계 | 실제 제목 28px, 원고 18px 세리프, 설명 14px, 상태·출처 12px 메타 |
| 설명색 | 의미 색 `secondaryInk`; Reader 밝은 종이는 ink2, 밤 종이는 기존 nightMeta |

소개·첫 원고 설정·홈·저장·결과·첫 장면 읽기 끝이 같은 행동 묶음을 사용한다. 입력/동의/보관함/설정 목록 전체를 280px로 제한하는 규칙이 아니다. Reader 본문은 기존 읽기 폭과 사용자 글자 크기를 유지한다. 소개의 큰 그라디언트와 홈 표지는 제거하거나 작은 카드로 대체하지 않는다.

## 탐색 화면 적용 — 10-23 후속

- 홈: 내용→행동32px, 주 행동280px. 새 결과가 있으면 ‘새 장면 읽기’ + 보조 ‘꿈 기록하기’, 없으면 ‘꿈 기록하기’ + 가능한 경우 ‘이어 읽기’. 새 결과와 중복되는 이어 읽기를 동시에 쌓지 않는다. 이전 장면은 보관함에서도 접근 가능하다. 대기 요약에는 실제로 존재하는 상태만 표시한다.
- 기록만 저장한 첫 꿈이 있으면 ‘첫 꿈이 남아 있어요’와 보관함 안내를 표시한다. 생성 전이라는 이유로 기록이 없는 상태처럼 표현하지 않는다. 빈 상태/오류 재시도의 행동도280px/간격32px를 공유한다.
- 보관함/설정: `MongPageHeader` 공유. 좌우24px·상단24px, 제목 영역 최소48px(긴 제목은 성장), 설명까지8px·아래32px. 제목28px·설명14px secondaryInk. 설정 상단의 반복 영문 eyebrow는 제거한다.
- 설정 목록: 그룹 사이24px, 행 상하16px, 제목16px/500, 설명14px secondaryInk·내부4px. 데이터/보안/고지 기능은 기존 상세 화면으로 연결한다.
- 보관함: 제목/필터/목록이 하나의 수직 스크롤을 공유한다. 필터는 기존 가로 스크롤. 행 상하16px, 기억/상태 태그는 Wrap. 글자 확대에서 날짜가 잘게 끊기지 않도록 본문 위로 옮긴다.
- 실제 GNB SafeArea를 사용하고 끝 여백32px만 더한다. GNB 바탕과 시스템 canvas·그라디언트·버튼 재질은 변경하지 않는다.

[탐색 화면 검증](ux-review/2026-10-23-shell/README.md). 로컬 검토용 설정의 온보딩/Orb 리뷰 도구는 생산 기능이 아니다.

## P4 상태 적용 — 시각 방향 변경 없음

첫 결과는 기존 리빌을 유지한다. 같은 기기에서 이미 예약한 결과는 ‘저장된 장면/장면 읽기’로 정적으로 열며 성장 수치를 다시 축하하지 않는다. 예약은 읽음/완독이 아니다. 결과 예약 실패는 ‘화면 상태 다시 저장’만 제공하고 실제 Reader 접근은 유지한다. 새 모션·팔레트·입력/STT 효과를 추가하지 않는다. [계약과 검증](ux-review/2026-10-23-p4-consumption/README.md).

## 완성본·PDF 적용 — 10-23 후속

- 설정의 ‘내가 완성한 책’에서 실제 저장한 완성본을 연다. 가짜 책이나 가짜 완료율을 채우지 않는다. 원고가 충분하지 않으면 조건만 설명하고 계속 기록하도록 돌아간다.
- 완성은 제목/선택 작가의 말 → 현재 문장 고정 안내 → 저장 확인 순서다. 각 단계의 주 행동은 하나다. 충돌은 현재 원고 재확인, 전송 대기는 같은 요청 재확인으로 분리한다. 제목·작가의 말은 실패 시 유지한다.
- 완성본은 기존 상세 프레임,24px 여백,32px 행동 간격,최대280px 유리 버튼을 사용한다. 본문은 MaruBuri18px×개인 읽기 배율, 출처 표시는 기존 설정을 따른다. 타이핑에 Orb/beam을 추가하지 않는다.
- 완성본 화면의 주 행동은 PDF 저장·공유, 다음 권은 보조 행동이다. 공유 취소/실패는 책을 삭제하거나 완료를 취소하지 않는다. 다음 권을 열어도 이전 책은 설정에서 접근한다.
- PDF는128×188mm, 표지/판권/차례/장면/선택 작가의 말/짧은 꿈 출처 부록 순서다. 기존 문장을 그대로 조판하며 원문 전체는 포함하지 않는다. 독서 순서가 고정된 스냅샷이지 LLM 개정본이 아니다.

## 유지하는 계약

### 10/26 시작 흐름 단순화 — 현재 사용자 요청

- 설치 문제 해결 이후 소개·설정의 설치 안내 진입을 제거한다. 기존 `/install.html` 링크는 같은 origin의 `/`로만 바로 연결한다. manifest id/start/scope와 사용자 계정·저장소는 그대로다. 구 preview origin의 자동 교차 도메인 이동은 복원하지 않는다.
- 동의는 짧은 목적/제공사 설명 → 선택 상세 ‘AI 처리 안내 보기’ → 연령/AI 처리 두 확인 → 하나의 주 행동 순서다. 전체 서버 고지·제공사 약관·데이터 안내·버전은 상세에 남긴다. 필수 확인/서버 정책·재동의 차단은 제거하지 않는다. 주 행동도 내용과 함께 스크롤하며 고정 footer와 겹치지 않는다.
- 첫 원고 설정은 제목·한 문장·‘시작하기’만 먼저 보인다. ‘이야기 설정’은 주 행동 아래의 보조 경로다. 펼친 설정값/실패 재시도는 유지한다. `MongFlowPage`의 24px/32px/280px 규격을 그대로 쓴다.
- **생산 Orb의 모양은 `thinking_orbs`의 `composing` 하나로 고정**한다. [Libraries.dev 원본](https://libraries.dev/orbs)의 ‘Thinking…’ 예시가 쓰는 촘촘한 띠 형태다. 실제 상태가 바뀌어도 node-web/희박한 궤도/다른 구형으로 교체하지 않는다. 실제 처리 상태와 접근성 문구는 별개로 유지한다. 초기 계정 확인의 내부 용어 ‘동의 기록’은 화면에 쓰지 않는다. 9개 형태 선택기는 로컬 컴포넌트 리뷰 전용이며 생산 흐름이 아니다.
- Orbs는 실제 대기에서만 사용한다. 입력·음성 전사는 계속 정적이다. 동작 줄이기는 같은 모양의 정지 프레임이며 숨은 route의 ticker 계약도 유지한다.
- 375×667의160% 글자에서 로고/단계 표시는 줄바꿈을 허용하고, 긴 안내/설정은 세로 스크롤한다. [변경 화면과 검증 경계](ux-review/2026-10-26-start-flow/README.md).

### 모바일 배포·성능 보정

- 배경의 시간 기반14초 움직임은 유지하되 repaint 알림을 최대30Hz로 제한한다. background에서는 정지하고 foreground에서 재개한다. 이는 실기기 FPS/터치 지연을 측정한 수치가 아니다.
- 버튼 blur 제거 실험은 기존 유리 외형을 바꿔 채택하지 않았다. 현재 글래스·눌림·행동 위계를 유지한다. PDF 전용 Bold 폰트는 초기 font manifest가 아니라 일반 asset으로 보관하고 내보낼 때 로드한다.
- iPhone 녹음은52px 마이크/정지 아이콘, 실제 기기 내 인식이다. 인식 실패 안내는 prompt 슬롯에 정적으로 표시해 키보드/저장 버튼을 덮지 않는다. RMS 연출·이벤트 전송은 제거한다.
- 웹은 녹음 버튼으로 위장하지 않고 ‘iPhone 앱 전용’ 설명과 마이크 안내를 표시한다. 설치 안내의 소개/설정 보조 경로는 위10/26 요청으로 제거했다. 기존 기록의 Safari/PWA/네이티브 자동 이전을 약속하지 않는다.

v0.8의 흰색/밤 canvas, 블루·라일락 초점, 중립 유리 버튼 재질과 눌림, 입력/STT 정적 상태, 실제 처리 Orb, 제한된 저장 스탬프를 유지한다. 원문·생성 본문·출처·U 잠금·엔진/Q 기준선·인증/동의는 변경하지 않는다. 한 화면의 시각적 주 행동은 하나이며 닫기/나중에/출처 보기는 보조 행동으로 남긴다.

검증과 전후 화면은 [10-23 리뷰](ux-review/2026-10-23-spacing/README.md)를 따른다. 로컬 Memory/mock 확인은 실제 AI·실기기 성능·공개 반영의 증거가 아니다.
