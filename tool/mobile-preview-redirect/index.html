주소창 없는 앱으로
다시 연결해 주세요.

이 주소는 예전 디자인 미리보기예요. 다른 도메인으로 자동 이동하면 설치한 앱 안에서도 브라우저 막대가 나타날 수 있어요. 이제 자동으로 이동하지 않아요.

정식 주소의 설치 안내를 Safari에서 열고, ‘홈 화면에 추가 → 웹 앱으로 열기’로 새 아이콘을 추가해 주세요.

정식 웹 앱 설치 안내

기존 아이콘이나 브라우저 데이터는 지우지 마세요. 쓰던 기록은 원래 주소에 남으며 자동 이전되지 않아요. 먼저 쓰던 곳의 설정 → 기록 관리에서 내보내 주세요.

이 페이지는 설치 안내뿐이며 계정 생성·로그인·AI 처리를 하지 않아요.
